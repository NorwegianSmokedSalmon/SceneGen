# 场景生成代码整理说明

从 Extended-GS 的 `scene_gen` 工作区提取场景生成相关源码，保留原算法目录和必要的 gsplat/CropFormer 依赖。原工作区已有的修改与结果没有被覆盖；新仓库沿用自己的初始化提交，不携带 Extended-GS 的全部 Git 历史。

## 本次整理

- 独立 README、阶段运行说明、已知问题、来源和许可证说明。
- 清理提取文件的行尾空格和末尾空行；补丁上下文保持原始字节。源哈希记录的是清理前内容。
- `.env.example`、根目录生成数据忽略规则；不包含令牌、数据集、权重、环境、缓存、生成模型或本机日志。
- 恢复 CropFormer 的 `mask2former/data` Python 模块，避免把源码目录误当数据集忽略。
- 固定 GLM 子模块提交与第三方安装提交；保留现有兼容补丁。
- WorldSculpt 基础 Python 改由 Conda 查找，并允许显式指定。
- 为室内准备入口增加 `SCENE_RUN_3D=0`，可只准备数据而不追加历史单视图 SAM 3D 生成。
- 显式米制尺度不再依赖历史生成椅子；估计模式可用 `--chair-mesh` 指定审核后的椅子。
- 保留最近的显式非金属材质、线性顶点色、法线与 Isaac 查看灯光修正。
- 将碎片、视角分布与轮廓拟合诊断整理为 `audit_object_completeness.py`。
- 增加轻量源码检查及 CI；保留已有的 4 项相机/物体回填几何回归。

`docs/source_provenance.json` 保存提取时源文件的哈希（独立仓库适配前）。环境 JSON 仅记录软件版本，不带用户绝对路径。历史实验记录明确说明原始产物不随源码发布。

## 验证边界

源码检查覆盖 Python 语法、shell 语法、关键入口、内部 Markdown 链接和不应发布的文件/常见令牌格式。已有数学回归和新 GLB 色彩导出做本地验证。完整性诊断使用原工作区现有生成物体实跑。

迁移发布不重新下载全部模型、不重训场景、不重新生成 66 个物体，也不等同全新机器的端到端安装验证。当前缺面和环绕多视图补全问题详见 `KNOWN_LIMITATIONS.zh-CN.md`。
