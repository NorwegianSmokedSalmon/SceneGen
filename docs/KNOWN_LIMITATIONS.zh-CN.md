## 原因

- 输入是场景照片中被遮挡的局部物体，不是环绕、完整、相互一致的物体视图。
- `multiview_shape_guide.py` 的轮廓多数投票统计所有视锥内投影，部分掩码缺失其实来自遮挡；这种负投票会缩小应保留的形状范围。轮廓之外的神经稀疏样本还会被约束筛掉。
- API 当前是原相机补图并做二维配准，没有完成一致的环绕新视角生成；通过二维配准不证明三维一致。
- MeshFix/体素固化可以让碎片各自闭合，无法证明它们拼成了完整、正确的家具。
- 选择分数主要是输入视图的轮廓覆盖与 IoU；仅警告弱拟合，没有全面阻止主体断裂的结果导出。
- 表面颜色是观测照片向顶点投影，带有原始阴影；未做独立 UV/PBR 纹理或反照率重建。

## 后续修复方向

1. 将可见前景、遮挡未知和确认背景分开处理，避免用未知区域裁掉几何。
2. 补完整物体轮廓与可靠的多方向视图，检查跨视图的一致性和姿态。
3. 对弱候选重新生成，联合检查连通主体、局部缺面、多视角重投影与合理结构。
4. 用灰模/法线检查几何，用颜色预览检查外观，分别验收；闭合度只作为拓扑指标。
5. 对要交互的物体补充质量、惯量、碰撞代理和接触/动态稳定性验证。

本次仓库整理保留现状并提供诊断工具，没有宣称上述算法问题已修复。
